title: v2.0.0 — PHP 8.3 and stronger runtime contracts
---

Released 2026-10-20. **PHP 8.3 is now required** in web, CLI, cron and worker processes.
An existing Composer `^1.1` constraint does not select this major release.

## Security and compatibility changes

- Resource ownership authorization now reads the same URL ID as the handler. Query,
  form or JSON IDs cannot substitute another authorization object. Invalid IDs fail
  closed, while non-URL legacy request fallbacks remain supported.
- Sensitive parameters redact annotated Better Route argument frames through nested
  credential/JWT/claim/signature/token helpers and default authentication closures.
  This does not scrub messages, object properties or onward native/custom callback
  frames. Implementations must repeat interface parameter annotations.
- Method `Override` attributes make PHP verify actual overrides at class load time.
  Typed constants keep their names and values.
- Existing final request/response, route and Woo query/policy DTOs become readonly
  classes. Undeclared dynamic properties fail; object-valued fields remain shallowly
  readonly. Use `RequestContext::withAttribute()` for request extension state.

No storage-schema, cache-key or idempotency-key migration is introduced from 1.1.2.
Read [migration guidance](../getting-started/migration) when upgrading from earlier
versions, especially deployments with outstanding idempotent retries.

These changes enforce security and quality contracts. No measured performance
improvement is claimed.

## Verification

The candidate passed **239 tests / 1311 assertions** on PHP 8.3, 8.4 and 8.5, plus
PHPStan level 6, coding standards and Composer validation. Native WordPress REST
ownership tests pass 48 assertions on PHP 8.3/8.5 using query, form and JSON inputs,
checking denial before repository effects and correct authorized URL handling.

WordPress 6.9.4 / WooCommerce 10.9.4 / MySQL 8.4 checks pass 117 service and 46 Analytics
assertions per PHP/runtime storage combination, with HPOS and CPT modes. External
OpenAPI/JSON Schema validation checks four documents, 33 standalone samples and 55
samples per native storage combination.

All six CI jobs are required before merge and run again after pushing main. Actions
use verified full commit pins and Node 24; Dependabot proposes updates. Synthetic
fixtures do not establish every deployment, extension, external identity provider
or complete background Analytics import.
