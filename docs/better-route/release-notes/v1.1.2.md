Released 2026-10-20. PHP minimum remains 8.1; no new database migration is required.
The later PHP 8.3 minimum development line is separate from this release.

- CustomerRolePolicy shares visibility across list/detail/mutations. Requests cannot widen
  configured roles; privileged users need explicit trusted opt-in. Native write capabilities
  and authorization/session metadata protection remain mandatory.
- Coupons gain state/status filters and numeric usage/expiry sorting before totals/pagination.
  Metadata is opt-in and internal keys cannot invoke native setters or modify usage counts.
  Derived state is a management summary; native WooCommerce decides checkout eligibility.
- Twelve opt-in native Analytics reports support bounded queries, comparison, current-user
  report permissions, historical import readiness and projected decimal-money DTOs.
- OpenAPI 3.1 gains unique operation IDs, nested local-ref checks, strict security metadata,
  proper empty objects, parameter serialization, native WP errors and Analytics contracts.

## Upgrade-visible changes

Review [migration guidance](../getting-started/migration): previously visible privileged
customers may now be hidden, metadata must be explicitly requested, and generated PATCH
client method IDs change from Update to Patch. Invalid/ambiguous OpenAPI configurations
now fail explicitly. Applications still supply custom schemas and actual auth definitions.

## Verification

The release candidate passed 218 tests / 668 assertions on PHP 8.1–8.4, PHPStan level 6,
coding standards and Composer checks. WP 6.9.4/Woo 10.9.4 CI on PHP 8.1/8.3 runs 117 service
and 46 Analytics assertions per HPOS/CPT mode. External validation checks four serialized
OpenAPI documents and 55 positive/negative schema samples, including 22 native response bodies.

Security, Woo domain and API source reviews have no open blockers. Background imports,
external identity providers and arbitrary third-party capability/metadata filters remain
outside this complete runtime matrix. See the individual feature pages for exact limits.
